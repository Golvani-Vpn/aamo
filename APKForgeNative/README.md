# APKForge Native — Phase 1

این یک پروژه‌ی واقعی **Kotlin + Android Studio + Gradle** است — نه یک اپ وب/Capacitor.
خروجی نهایی یک `.apk` واقعی است که با Gradle واقعی ساخته می‌شود، نه یک WebView.

## این فاز (Phase 1) واقعاً چه کاری انجام می‌دهد

- باز کردن هر فایل APK/ZIP از طریق Storage Access Framework (بدون نیاز به دسترسی ذخیره‌سازی).
- خواندن کامل آرشیو در حافظه با `java.util.zip` — بایت‌به‌بایت، بدون هیچ shim یا داده‌ی جعلی.
- نمایش لیست فایل‌ها، ویرایش فایل‌های متنی (UTF-8) در ادیتور.
- خروجی گرفتن یک ZIP/APK جدید: فایل‌های باینری دست‌نخورده کپی می‌شوند، فایل‌های متنی ویرایش‌شده جایگزین می‌شوند.
- امضای قبلی (`META-INF/*.SF`, `*.RSA`, `MANIFEST.MF`) هنگام خروجی حذف می‌شود چون بعد از تغییر محتوا دیگر معتبر نیست.

## این فاز عمداً چه کاری انجام نمی‌دهد

- **امضای واقعی APK (V1/V2/V3):** خروجی این فاز *بدون امضا* است. Phase 2 با کتابخانه‌ی رسمی
  خود گوگل (`com.android.tools.build:apksig` — همان چیزی که ابزار `apksigner` استفاده می‌کند)
  امضای واقعی اضافه می‌کند.
- **دیکامپایل/کامپایل DEX↔Smali:** نیاز به کتابخانه‌های `smali`/`baksmali` دارد؛ Phase 3، با تست
  واقعی روی دستگاه چون سازگاری‌شان با ART باید تأیید شود.
- **کامپایل واقعی منابع باینری (AAPT2):** AAPT2 یک باینری native برای لینوکس/مک/ویندوز است؛
  نسخه‌ای که *روی خود گوشی اندروید* اجرا شود رسماً وجود ندارد. این محدودیت واقعی و شناخته‌شده است،
  نه یک نقص قابل رفع با چند خط کد. راه‌حل واقع‌بینانه: کامپایل منابع را می‌توان به یک مرحله‌ی
  کمکی روی GitHub Actions (که لینوکس واقعی با AAPT2 واقعی دارد) سپرد، نه روی خود دستگاه.

## بیلد

### روی GitHub Actions (توصیه‌شده)
1. محتوای این ریپازیتوری را در GitHub push کن.
2. تب **Actions → Build APKForge Native (debug APK)** را باز کن.
3. artifact با نام `APKForgeNative-debug` را دانلود کن.

این workflow عمداً از `gradlew`/`gradle-wrapper.jar` دست‌ساز استفاده نمی‌کند — چون یک باینری
Gradle Wrapper واقعی را نمی‌شود با دست/AI به‌درستی تولید کرد بدون ریسک خرابی. به‌جایش از اکشن رسمی
`gradle/actions/setup-gradle` استفاده شده که نسخه‌ی مشخص‌شده‌ی Gradle (۸.۷) را مستقیماً و معتبر نصب می‌کند.

### محلی (Android Studio)
1. پوشه را در Android Studio باز کن (Open → این پوشه).
2. Android Studio خودش Gradle Wrapper واقعی را می‌سازد (چون IDE ابزار رسمی برای این کار دارد).
3. Run ▶ یا Build → Build APK(s).

## نسخه‌ها
- Android Gradle Plugin: 8.5.0
- Kotlin: 1.9.24 (با Compose Compiler 1.5.14 — جفت سازگار شناخته‌شده)
- compileSdk / targetSdk: 34، minSdk: 26
- Gradle: 8.7 (روی CI؛ محلی از طریق Android Studio)

⚠️ این نسخه‌ها دستی و بر پایه‌ی دانش نویسنده انتخاب شده‌اند و **کامپایل واقعی‌شان روی این محیط تست
نشده** (این محیط به `registry` های Gradle/Maven دسترسی شبکه ندارد). اگر GitHub Actions هنگام بیلد
خطا داد، پیام دقیق خطا را بفرست تا اصلاح شود — این روش نرمال و واقعی رفع‌اشکال است، نه نشانه‌ی
شکست پروژه.
